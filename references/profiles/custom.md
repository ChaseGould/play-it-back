# Profile: custom

For anything the other profiles don't fit: a lyric video, a birthday
montage, a short film, a meme remix, a mix of formats.

Build a profile with the user from the interview answers, write it to
the project as `bible/profile.md`, and get their OK before stage 1. It
needs only these sections:

1. **Timing:** what is the clock (song, narration, dialogue, fixed
   length, or a mix, and which wins where they conflict)?
2. **Consistency:** what must look the same in every shot, and the
   references for it.
3. **Audio:** sources for voice, music, and SFX, with rights status.
4. **Lip sync:** which shots, if any, and the plan to test one first.
5. **Motion mix:** the still, loop, animated split (`motion-policy.md`).
6. **Stages:** which of the standard stages apply, which are `n/a`, and
   any extra stage.
7. **Rules:** audience rules and anything the user cares about.

Borrow freely from the closest profiles; say which.

At wrap-up, if the user wants to reuse it and this skill's files are
writable, copy `bible/profile.md` to `references/profiles/<name>.md`
with a "Lessons from use" section and add a row for it to the table in
`SKILL.md`. If the skill is read-only (uploaded), give the user the file
and the table row to add to their copy.
